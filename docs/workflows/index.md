# Operational Workflows
{: .no_toc }

Practical, real-world guides for integrating PatchProof into studio operations and delivery pipelines.
{: .lead }

Addressables release verification should not be an afterthought performed minutes before a store upload. These step-by-step operational workflows explain how development teams, QA analysts, and DevOps engineers weave rehearsals into their daily development cadences.

---

## Workflow Guides

* **[First Rehearsal Walkthrough]({{ site.baseurl }}/docs/workflows/first-rehearsal/):** Complete step-by-step guide to executing your very first Addressables rehearsal in the Editor.
* **[Rehearsing a Live Update]({{ site.baseurl }}/docs/workflows/rehearsing-an-update/):** Validating a candidate patch against your currently live production release.
* **[Simulating Network Failure & Drops]({{ site.baseurl }}/docs/workflows/network-failure-simulation/):** Stress-testing download resumability under severe packet loss and socket drops.
* **[Rollback Rehearsal Procedure]({{ site.baseurl }}/docs/workflows/rollback-rehearsal/):** Verifying emergency catalog rollback procedures before pushing live.
* **[CI/CD Pipeline Integration]({{ site.baseurl }}/docs/workflows/ci-pipeline/):** Wiring headless rehearsals into GitHub Actions, GitLab, and automated build servers.
