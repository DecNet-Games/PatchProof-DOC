## Communicating Quality Across Teams

An engineering tool is only as effective as the decisions it enables:
* **Production Directors** need high-level confidence badges before approving marketing pushes.
* **Release Managers** need clear verification checklists confirming that no unverified edge cases were skipped.
* **DevOps Engineers** need machine-readable JSON metrics to drive automated deployment gates.

PatchProof's **Reporting Engine** ([`ReportGenerator.cs`](file:///c:/Users/anshw/Projects/Unity-Assets/Decnet_Unity_5_Flagships_15_Standalone_Docs/04_PatchProof_Addressables_Lab/PatchProof/Assets/Decnet/PatchProof/Core/Reporting/ReportGenerator.cs)) generates both rich executive HTML dossiers and structured JSON summaries.

## Generating Reports in the Editor

1. Open `Tools > PatchProof > Rehearsal Room`.
2. After running a scenario matrix, click **"Export Release Report"** in the top toolbar.
3. Select format: **HTML Executive Report**, **JSON Telemetry**, or **Both**.
4. PatchProof renders the files to your project's `Reports/` directory and automatically opens the HTML report in your default browser.

> ### Pro Tip: Mandatory Privacy Disclaimers
> All exported reports automatically append a privacy footer: *"Confidential - Pre-Release Compatibility Evidence. Generated by Decnet PatchProof"*. URLs containing tokens or internal IP addresses are pre-sanitized by the redaction engine.
